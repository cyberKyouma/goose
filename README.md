# 鹅
记账工具

## 功能
1. 记账。打开应用后能够快速记账。记账内容包括收入/支出、分类、时间
2. 能够根据一级分类、二级分类、和时间等条件查询流水
3. 界面简洁美观
4. 提供可视化图表对账目进行分析
5. 数据存储在本地。也可通过配置服务器上传云端

## 技术栈
- Expo SDK 55 + React Native 0.83 + TypeScript
- Zustand 状态管理
- React Navigation 7 (Bottom Tabs + Native Stack)
- AsyncStorage (Web) / expo-sqlite (Native) 双端存储
- react-native-chart-kit 图表
